# UI/UX аудит сайта cdkl5-russia.ru

Дата: 2025-08-28 · Стек: Ktor 3.1 + FreeMarker + Bootstrap 5.3 (CDN) · Проверено: локальный рендер всех 4 страниц (desktop 1440px + mobile 390px)

---

## 1. Текущее состояние

**Что есть:** 4 страницы (`/`, `/about-cdkl5`, `/genetics`, `/treatment`) — длинные медицинские статьи с hero-баннером, боковым оглавлением (на статьях), аккордеоном симптомов, 2 таблицами. Шапка с текстовым лого, футер с партнёром и ВК.

**Аудитория:** родители, получившие диагноз ребёнку (шоковое состояние, мобильные телефоны, нужна быстрая навигация и поддержка), + врачи, ищущие информацию о редком диагнозе.

---

## 2. Критичные проблемы (P0)

### 2.1. Контраст заголовков h2 — FAIL WCAG (читаемость!)
Белый текст на сине-градиентной подложке (`styles.css` → `h2 { background: linear-gradient(to right, #018fff, #a5d7ff) }`):
- на тёмном конце градиента: **3.29:1** (норма AA — 4.5:1)
- на светлом конце: **1.53:1** — длинные заголовки («Молекулярная основа заболевания и его возможная обратимость») буквально растворяются на светлом фоне. Видно на всех скриншотах.

**Фикс:** однотонная тёмная подложка (например, `#1D3557`/`#563D7C`) или тёмный текст на светлом акцентном баре.

### 2.2. Нет пути пользователя «Вам поставили диагноз — что делать?»
Главная страница — 5 абзацев сплошного текста, нет ни одной ссылки на разделы, нет CTA. Главная задача сайта — довести растерянного родителя до нужной статьи и до сообщества (ВК). Сейчас это не сделано.

### 2.3. Оглавление недоступно на мобильных
`.col-lg-2.d-none.d-md-block` — sticky TOC скрыт на телефонах, где он нужен больше всего (статьи по 550+ строк). На десктопе якорные переходы уезжают под fixed-навбар: нет `scroll-margin-top` у `h2`.

### 2.4. SEO/шэринговые основы
- нет `meta description` и OG-тегов (важно: ссылку на сайт будут кидать в родительских чатах!)
- `<title>` несогласован: «Сообщество CDKL5 - Сообщество пациентов CDKL5» на главной
- нет `robots.txt` и `sitemap.xml`
- нет кастомной 404

### 2.5. Тяжёлые и лишние внешние ресурсы
- **Noto Serif загружен, но не используется нигде** (весь CSS — только Noto Sans)
- Google Fonts грузит variable-шрифты в диапазоне `100..900` для двух семейств — можно ужать в 3 начертания с cyrillic-сабсетом
- **Font Awesome (весь CDN) ради одной иконки ВК** → inline SVG
- Все 3 CDN (jsdelivr, cdnjs, googleapis) — точка отказа для РФ-аудитории; Bootstrap CSS тоже можно засабсетить/заменить, но как минимум самохостинг шрифтов

## 3. Структурные проблемы (P1)

### 3.1. Незавершённые разделы (полузакопанные фичи)
| Артефакт | Состояние |
|---|---|
| `val aboutUs = "О нас"` в `Templating.kt:20` | объявлен, в меню не используется |
| `templates/pages/parents/russian-community.ftl` | **пустой файл (0 строк)** |
| `templates/pages/parents/international-communities.ftl` | **пустой файл (0 строк)** |
| `templates/news.ftl` | есть, роута нет; внутри сломанный `<#if item??>` (упадёт, если подключить как есть) |
| `static/img/logo.svg` | есть, нигде не используется (в шапке текстовый лого) |

Меню поддерживает вложенность (`MenuItem.children`, dropdown в `header.ftl`), но структура плоская из 3 пунктов. Раздел «Родителям» — очевидный кандидат в dropdown.

### 3.2. Читаемость длинных статей
- ширина колонки `col-lg-10` ≈ 950px → **110–120 знаков в строке** (комфорт — 60–80, `max-width: 70ch`)
- абзацы по 15+ строк без визуальных пауз; на странице «О лечении» есть незакрытый `<p>` (строка ~66)
- статьи почти не связаны между собой: нет «Читайте также» / prev-next / хлебных крошек
- таблицы без `.table-responsive` → горизонтальный скролл на мобильных ломает вёрстку

### 3.3. Дизайн-система отсутствует
В `:root` заявлена пастельная палитра (#A8DADC / #F1FAEE) — **не используется вообще**. Фактически: фиолетовый навбар `rgb(86,61,124)` (это фирменный фиолетовый документации Bootstrap), лавандовый `#cbbde2`, синий градиент заголовков, синие акценты симптомов `#4e73df`. Четыре языка цвета, ни одного переиспользуемого компонента (кнопок, карточек, callout-блоков нет вовсе — весь контент это h2 + p).

## 4. Доступность (a11y)

- контраст h2 (см. 2.1) — блокер
- аккордеон: у всех элементов `aria-labelledby="heading2"`, при этом id `heading2` не существует (10 повторов)
- на главной пустой `<h1></h1>` перед hero (два h1 на странице)
- нет skip-link, нет стилей `:focus-visible`
- `id="what—is—cdkl5"` с em-dash — невалидные/неоткрываемые якоря
- `lang="ru"` есть ✅, навигация контрастная ✅ (5.06:1), body-текст ✅ (15.4:1)

## 5. Мелочи (P2)

- `favicon.png` 592×576 / 50KB → набрать 32/180px иконок
- static-ресурсы Ktor отдаются без кэш-заголовков и сжатия (нет `Compression` плагина)
- hero 400px фиксированной высоты на мобильном — слишком высоко, кроп `cover` рвёт картинки
- тень `h1 { text-shadow: 1px 1px 1px black }` на всех h1, включая будущие не-hero
- футер: нет e-mail, нет Telegram (аудитория родительских чатов), нет логотипа партнёра
- закомментированные ленты «Элемент 2» ×8 в `about-cdkl5.ftl`, дубли кода — при конвертации контента в данные (FTL-макрос аккордеона) уйдут сами

## 6. План улучшений

1. Контраст h2: тёмная подложка / тёмный текст
2. `scroll-margin-top: 120px` для `[id]`, TOC на мобильных как `<details>` «На этой странице»
3. Мета-теги + OG + `robots.txt` + `sitemap.xml` + 404
4. Самохостинг шрифтов (Noto Sans, cyrillic+latin, 400/500/700), убрать Noto Serif и Font Awesome (inline SVG для ВК)
5. `max-width: 70ch` на текстовых колонках, `.table-responsive`, закрыть `<p>`, почистить aria аккордеона

### Переработка главного (1–2 недели)
1. **Главная:** hero + карточка-CTA «Только что получили диагноз?» → короткий маршрут к 3 статьям + заметный блок сообщества (ВК) + новости

4. Единая палитра и компоненты: карточки, callout («Важно», «Статистика»), цитаты родителей, кнопки
5. Кросс-ссылки между статьями («Читайте также»), breadcrumbs

### Идеи для контента (обсудить)
